Guide de prise en main

Notice d'utilisation de votre site

Découvrez comment modifier vos textes, vos photos et mettre votre site en ligne en quelques minutes.

📁 1. Que contient votre dossier ?

Tous les fichiers de votre site sont réunis ici. Voici à quoi sert chaque fichier :

├── index.html ➜ Page d'accueil
├── menu.html ➜ Carte / Services
├── reservation.html ➜ Tarifs et réservations
├── gallery.html ➜ Galerie photos
├── histoire.html ➜ Présentation de l'établissement
├── contact.html ➜ Formulaire et coordonnées
├── texte.html ➜ Page générique (Mentions légales / CGV)
├── success.html ➜ Page affichée après un paiement réussi
├── styles.css ➜ Mise en page et couleurs du site
├── scripts.js ➜ Fonctions interactives (calculateur, paiement)
└── api/ ➜ Fonctions serveur (paiement Stripe, emails)

✏️ 2. Comment modifier vos textes et images ?

Aucune compétence technique avancée n'est requise. Deux méthodes s'offrent à vous :

Méthode 1 : Modification simple dans les fichiers

  1. Faites un clic droit sur n'importe quel fichier .html (ex: index.html).
  2. Choisissez Ouvrir avec ➜ Bloc-notes (ou VS Code).
  3. Remplacez simplement les phrases écrites entre les balises par les vôtres.
  4. Enregistrez le fichier (Touches Ctrl + S).

Méthode 2 : Remplacer les photos

Pour remplacer une image, mettez vos nouvelles photos dans un dossier nommé images et remplacez les liens dans les fichiers HTML, ou réutilisez simplement le même nom de fichier photo.

🚀 3. Comment mettre votre site sur Internet ?

Option A : Hébergement gratuit (Vercel ou Netlify) — Recommandé

  1. Rendez-vous sur Vercel.com ou Netlify.com et créez un compte gratuit.
  2. Glissez-déposez simplement tout votre dossier sur leur site.
  3. Votre site sera immédiatement en ligne avec une adresse web sécurisée (HTTPS) !

Option B : Hébergeur traditionnel (Hostinger, OVH, LWS...)

Connectez-vous au gestionnaire de fichiers de votre hébergeur et envoyez l'intégralité du contenu du dossier dans votre répertoire public_html ou www.

💳 4. Configurer le paiement en ligne (Stripe)

Le module de réservation redirige vos clients vers Stripe Checkout, qui collecte lui-même le numéro de carte sur sa propre page sécurisée : ce site ne manipule et ne stocke jamais de coordonnées bancaires.

Étape 1 : Créer votre compte Stripe

Rendez-vous sur stripe.com, créez un compte, puis récupérez votre clé secrète dans le menu Développeurs > Clés API.

Étape 2 : Ajouter les variables d'environnement

Sur votre hébergeur (Vercel ou Netlify), dans les réglages du projet, ajoutez :

  • STRIPE_SECRET_KEY — votre clé secrète Stripe
  • STRIPE_WEBHOOK_SECRET — voir étape 3 ci-dessous
  • RESEND_API_KEY — pour l'email de confirmation automatique (compte gratuit sur resend.com)

Étape 3 : Créer le webhook Stripe

Dans le tableau de bord Stripe, créez un webhook pointant vers https://votre-domaine.com/api/webhook, en sélectionnant l'événement checkout.session.completed. Copiez la clé de signature générée dans STRIPE_WEBHOOK_SECRET.

Étape 4 : Modifier les tarifs

Les prix des chambres et des options se modifient dans api/create-checkout-session.js (objet ROOM_CATALOG). Reportez tout changement de prix dans scripts.js (objet ROOMS) pour que le tarif affiché au client avant paiement reste exact.

Tant que ces variables ne sont pas configurées, le bouton de réservation ne pourra pas créer de session de paiement.
