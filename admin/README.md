# 📊 Mon Admin - Guide d'Utilisation

## 🎉 Bienvenue dans votre espace de gestion !

Vous avez acheté un site web professionnel. Ce guide vous explique comment le modifier facilement, sans toucher au code.

---

## 🔐 Connexion

1. Ouvrez votre navigateur
2. Allez à : `https://votre-site.com/admin/`
3. Entrez votre mot de passe
4. Cliquez sur "Accéder à l'Admin"

**Mot de passe :** Vous l'avez reçu par email lors de votre achat.

---

## 📊 Tableau de Bord

Le tableau de bord affiche un aperçu de votre site :
- Le nom de votre établissement
- Vos couleurs actuelles
- Nombre d'images
- Dernière sauvegarde

---

## 🎨 Personnalisation

### Changez vos couleurs

1. Allez dans **Personnalisation**
2. Cliquez sur le carré de couleur
3. Choisissez votre couleur
4. La valeur hexadécimale s'affiche automatiquement

**Les 3 couleurs principales :**
- **Couleur principale** : Titres, boutons
- **Couleur secondaire** : Détails, accents
- **Couleur d'accentuation** : Mises en avant, prix

### Changez les polices

1. Allez dans **Personnalisation**
2. Choisissez une police pour les titres
3. Choisissez une police pour le texte
4. Les changements s'appliquent immédiatement

---

## 📝 Contenu

Modifiez le texte de votre site :

1. Allez dans **Contenu**
2. Remplissez les champs :
   - **Nom de votre établissement** : Apparaît partout
   - **Titre principal** : Le gros titre de l'accueil
   - **Sous-titre** : La description sous le titre
   - **Téléphone, Email, Adresse** : Vos coordonnées

Tous les changements s'affichent en direct dans l'aperçu.

---

## 🖼️ Images

### Ajouter votre logo

1. Allez dans **Images**
2. Cliquez sur la zone "Glissez-déposez votre logo"
3. Sélectionnez une image depuis votre ordinateur
4. Le logo s'affiche immédiatement

**Format recommandé :** PNG avec fond transparent (200x200px)

### Ajouter des photos

1. Allez dans **Images**
2. Cliquez sur la zone "Glissez-déposez vos images"
3. Sélectionnez une ou plusieurs photos
4. Les images apparaissent dans la galerie

**Astuce :** Vous pouvez aussi **glisser-déposer** directement les fichiers !

---

## 💾 Sauvegarder

### Sauvegarder vos changements

1. Après vos modifications, cliquez sur **Sauvegarder** (bouton vert)
2. Un message confirme la sauvegarde
3. L'heure s'affiche pour la dernière sauvegarde

**Important :** Si vous quittez sans sauvegarder, vos changements seront perdus !

### Prévisualiser

Cliquez sur **Prévisualiser** pour voir votre site en temps réel dans le panneau de droite.

---

## ⚙️ Paramètres

### Télécharger votre configuration

1. Allez dans **Paramètres**
2. Cliquez sur **Télécharger la configuration**
3. Un fichier JSON se télécharge
4. Conservez ce fichier en sécurité (sauvegarde)

### Réinitialiser le mot de passe

1. Allez dans **Paramètres**
2. Cliquez sur **Réinitialiser le mot de passe**
3. Vous recevez un email avec un nouveau mot de passe

### Réinitialiser le site

⚠️ **ATTENTION :** Cela supprime TOUT. C'est irréversible !

---

## ❓ Questions Fréquentes

**Q : Mon mot de passe ne fonctionne pas**
A : Allez à `/admin/login.html` et cliquez sur "Réinitialiser votre mot de passe"

**Q : Où se trouvent mes données ?**
A : Elles sont sauvegardées localement dans votre navigateur (localStorage)

**Q : Puis-je accéder à l'admin depuis mon téléphone ?**
A : Oui ! L'admin fonctionne sur tous les appareils

**Q : Comment ajouter une nouvelle page ?**
A : Contactez le support. La création de pages demande du développement.

**Q : Mes changements ont disparu !**
A : Vous avez vidé vos cookies/données du navigateur. Restaurez votre sauvegarde JSON.

## 💡 Conseils

1. **Sauvegardez régulièrement** - Cliquez sur le bouton "Sauvegarder" après chaque modification
2. **Testez les changements** - Utilisez l'aperçu pour voir le résultat en direct
3. **Gardez une sauvegarde** - Téléchargez votre configuration tous les mois
4. **Utilisez des images optimisées** - Les images JPG/PNG de moins de 5MB se chargent mieux
5. **Évitez les mots de passe simples** - Changez "admin123" par quelque chose de plus fort
